# Расширение OpenCart 4.x сервиса «Экспресс Платежи: Банковские карты»

Расширение CMS OpenCart для интеграции с сервисом «Экспресс Платежи». Расширение позволяет производить приём платежей с помощью банковских карт.

[Инструкция для установки и настройки](https://express-pay.by/extensions/opencart-4-x/acquiring)

[Наш Youtube канал с опубликованными видео по расширениям](https://www.youtube.com/c/express-pay-by)

## Описание

Расширение OpenCart добавляет платёжный метод «Экспресс Платежи: Банковские карты». При оформлении заказа клиент выбирает этот способ оплаты, его перенаправляют на платёжную страницу сервиса, после оплаты — возвращают обратно в магазин. Статус заказа обновляется автоматически по серверным уведомлениям от сервиса.

Расширение использует API v1 сервиса (`web_cardinvoices`) и формирует цифровую подпись запросов (HMAC-SHA1).

## Возможности

- Приём платежей банковскими картами через API v1 (`web_cardinvoices`).
- Тестовый режим (Sandbox) с автозаполнением тестовых параметров.
- Формирование цифровой подписи (HMAC-SHA1) для подписи счетов.
- Приём серверных уведомлений о статусе заказа с проверкой подписи.
- Автоматическая смена статуса заказа.
- Настройка текста описания заказа и сообщения об успешной оплате.
- Логирование событий в файл.

## Требования

- OpenCart 4.0.x;
- PHP 8.0 и выше;
- Исходящий доступ к API сервиса:
  - `https://api.express-pay.by/v1/` (production)
  - `https://sandbox-api.express-pay.by/v1/` (тестовый)

## Установка

### Шаг 1. Загрузка расширения

1. В админке OpenCart перейдите в **Модули / Расширения → Установка расширений**.
2. Нажмите кнопку **«Загрузить»** и выберите файл `expresspay_card.ocmod.zip`.
3. Дождитесь окончания загрузки.
4. После добавления модуля в установленных расширениях нажмите **«Установить»**.

### Шаг 2. Установка модуля оплаты

1. Перейдите в **Модули / Расширения → Модули / Расширения**.
2. Выберите тип расширения — **Модули оплаты**.
3. В списке найдите «Экспресс платежи: Банковские карты» и нажмите **«Установить»**.

### Шаг 3. Настройка

1. Нажмите **«Редактировать»** напротив модуля.
2. Заполните настройки (см. раздел «Настройка»).
3. Нажмите **«Сохранить»**.

Проверка установки:

- Доступна страница настроек модуля.
- Расширение отображается в списке модулей оплаты со статусом «Включено».

## Настройка

Настройка выполняется в админке: **Расширения → Модули оплаты → Изменить**.

| Поле | Описание | Пример |
|---|---|---|
| Название метода оплаты | Отображается при выборе способа оплаты | Экспресс платежи: Банковские карты |
| Использовать тестовый режим | Включает Sandbox и автозаполняет тестовые параметры | Да |
| Токен | API-ключ производителя услуг | `a75b74cbcfe446509e8ee874f421bd68` |
| Номер услуги | Номер услуги в системе express-pay.by | `6` |
| Секретное слово для подписи счетов | Ключ для формирования HMAC-SHA1 | `sandbox.expresspay.by` |
| Использовать цифровую подпись для уведомлений | Проверка поля Signature в уведомлениях | Да |
| Секретное слово для уведомлений | Ключ для проверки подписи уведомлений | `YOUR_NOTIFICATION_SECRET` |
| Адрес для получения уведомлений | URL для уведомлений (задаётся в личном кабинете ExpressPay) | *заполняется автоматически* |
| Адрес API | Базовый URL production API | `https://api.express-pay.by/v1/` |
| Адрес тестового API | Базовый URL sandbox API | `https://sandbox-api.express-pay.by/v1/` |
| Описание заказа | Текст, который видит клиент при оплате | `Заказ номер ##order_id## в магазине` |
| Сообщение при успешном создании счёта | Текст на странице успеха | `Номер вашего заказа: ##order_id##` |
| Статус | Включает/отключает метод оплаты | Включено |
| Порядок сортировки | Позиция в списке способов оплаты | `0` |
| Статус нового заказа | Устанавливается при получении уведомления «ожидает оплаты» | В обработке |
| Статус оплаченного заказа | Устанавливается при уведомлении «оплачен» | Оплачен |
| Статус заказа при ошибке | Устанавливается при ошибке/отмене | Отменён |

## Использование

1. Клиент оформляет заказ и выбирает «Экспресс платежи: Банковские карты».
2. Магазин формирует параметры счёта и подпись и перенаправляет клиента на оплату (`ReturnType=redirect`) на `.../web_cardinvoices`.
3. После оплаты сервис возвращает клиента на страницу успеха магазина.
4. Серверное уведомление отправляется на URL из настроек (POST: `Data` + `Signature`).
5. Магазин проверяет подпись и изменяет статус заказа.

### Проверка в тестовом режиме

1. Включите «Использовать тестовый режим» — параметры подставятся автоматически.
2. Оформите заказ и оплатите через sandbox-сценарий сервиса.
3. Проверьте статус заказа в админке.
